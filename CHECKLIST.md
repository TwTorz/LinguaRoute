# Hackathon Checklist

## Tonight
- [ ] Log in to GitHub: `gh auth login` (pick GitHub.com → HTTPS → browser)
- [ ] Read the hackathon rules: theme, judging criteria, submission format, deadline
- [ ] Check what the submission needs (Devpost? video? live link?)
- [ ] Charge your laptop, phone, and headphones
- [ ] Pack: charger, extension cord, water bottle, snacks, student ID
- [ ] Get a few starter ideas down in `IDEAS.md`
- [ ] Sign up for anything you might need (free API keys, Vercel/Netlify, etc.)
- [ ] Sleep 😴

## First hour
- [ ] Form the team; swap GitHub usernames and contact info
- [ ] Pick ONE idea (use the scoring table in `IDEAS.md`)
- [ ] Decide the tech stack: stick with what the team already knows
- [ ] Create the repo and add teammates as collaborators
- [ ] Split up the work: who does frontend / backend / design / pitch
- [ ] Define the **MVP**: the smallest version that still demos well

## During
- [ ] Commit and push often (at least every hour)
- [ ] Get something working end-to-end early, then improve it
- [ ] Check in as a team every 2–3 hours
- [ ] Stop adding features about 3 hours before the deadline
- [ ] Take breaks, eat, drink water

## Last 3 hours
- [ ] Freeze features, fix bugs only
- [ ] Deploy it or have a reliable local demo
- [ ] Record a backup demo video (in case the live demo breaks)
- [ ] Finish `README.md` with screenshots
- [ ] Practice the pitch (see `PITCH.md`) at least twice
- [ ] Submit **early**; you can usually edit afterward
